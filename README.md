[Click here to open the live application]

## 📌 About the Project
This project analyzes global child malnutrition data and uses machine learning to predict child stunting rates based on country, year, and income classification.

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Random Forest Regression
- Streamlit

## 📊 Dataset
Source: [Kaggle – Malnutrition Across the Globe](https://www.kaggle.com/datasets/ruchi798/malnutrition-across-the-globe)

## 📈 Model Results
- MAE: 4.25
- RMSE: 5.62
- R² Score: 0.863

## 🚀 Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ⚠️ Disclaimer
This project is for educational purposes. Predictions are estimates based on historical country-level data and are not medical diagnoses.
